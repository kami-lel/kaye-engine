# Dify App Kaye Chat Documentation

## Input Fields

#### `show_meta_content`

A `boolean` indicate whether to show meta content for debugging after main response content.





#### `role_override`

(Instead of deciding role during sensing,) force use **role given** by user.

```json
[
  "chat",
  "rapid",
  "coder"
]
```





#### `llm_override`

(Instead of deciding LLM during sensing, directly generated by seeing or decided from difficulty sensed,) force use **LLM given** by user.

```json
[
  "rapid",
  "chat",
  "think",
  "think-think",
]
```





#### `difficulty_override`

When `role_override` or sensed role is `"coder"`, force use difficulty value (from `0.0` to `1.0`) given by user.
